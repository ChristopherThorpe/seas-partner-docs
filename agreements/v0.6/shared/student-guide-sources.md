# Student Guide: sources and verification status (for counsel)

This list supports `student-guide.md`. It records each source the drafter relied on, and how far the drafter could check it. It is not part of the guide that students read.

> **Note for counsel:** network limits stopped the drafter from opening most web pages. The page fetcher could not reach www.copyright.gov, media.cadc.uscourts.gov, or www.govinfo.gov, and a download from codeload.github.com was refused. Sources marked "Search results only" were checked against search-engine summaries of the page, not the page itself. Open and check each of them before the guide is used.

Status key: **Opened** means the drafter read the full text. **Search results only** means the drafter checked the statement against a search-engine summary of the page. **Not checked** means the link or statement was carried over without checking.
